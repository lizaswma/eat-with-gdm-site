# eat-with-gdm-site

Privacy policy, terms and support pages for the Eat with GDM iOS app, served by
GitHub Pages at https://eatwithgdm.mamabuilds.dev (same setup as `tiny-tongues-site`).

`privacy.html` and `terms.html` are copies of
`gdm-diet-manager/CoachProxy/public/`. If you edit the policy, edit it in one place
and copy it to the other so they don't drift.
