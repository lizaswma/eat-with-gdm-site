# eat-with-gdm-site

Privacy policy, terms and support pages for the Eat with GDM iOS app, served by
GitHub Pages at https://eatwithgdm.mamabuilds.dev (same setup as `tiny-tongues-site`).

`privacy.html` and `terms.html` are also kept in the app's source repo. If you edit
the policy, update both copies so they don't drift.
